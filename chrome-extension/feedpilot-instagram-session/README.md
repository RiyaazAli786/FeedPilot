# FeedPilot Instagram Session Opener

This unpacked Chrome extension lets the FeedPilot admin dashboard open an Instagram profile using a saved account session.

## Install

1. Open `chrome://extensions`.
2. Enable `Developer mode`.
3. Click `Load unpacked`.
4. Select this folder: `chrome-extension/feedpilot-instagram-session`.
5. Refresh the FeedPilot dashboard.

After installation, open the dashboard `IG Sessions` tab and click `View`.
