Controls every Android client's runner pacing: the gap between individual actions, how often an idle account re-polls for new orders, and — in Random mode (an account set to both Follow and Like) — how many consecutive same-type actions it does before switching type and cooling down. A running device picks up a change within about a minute, no app release needed.

Order Claiming ▼

When a device claims a batch, those orders become invisible to other devices until the device finishes them, releases them, or the claim times out.

⚡ Per-Activity Streak Counts (Random mode) ▼

How many consecutive actions of each type run before the runner switches to the next type and enters the cooldown.

🛑 Daily Action Limits & Cooldown ▼

Set maximum daily actions per account. Once an account reaches an activity's daily quota, it stops picking that order type. Once all activity limits are reached, the account enters cooldown for the specified minutes.

Action Coin Pricing & Referral Schema

Configure coin rewards granted per completed action for Normal vs Upgraded accounts, and the commission percentage referrers earn.

Order Purchase Coin Prices (Buy Rates)

Configure the amount of coins charged per unit (follower, like, comment, repost, save, story view) when a user places an order.
