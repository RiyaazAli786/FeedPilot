Backup / Restore

This page needs two separate credentials: your usual admin key, and a second backup passcode held apart from it. Neither is enough on its own.

Export a backup

Downloads every user, device, linked Instagram account, wallet (with its coin history), app order, withdrawal, worker task, subscription/password-reset request, coin transfer, and the runner config as one JSON file — everything a backend migration needs to not lose data.

Restore from a backup

Reads a backup file back in. This is an upsert — rows already in the database with a matching id are updated to the file's values, everything else is left alone. Safe to run against a database that already has some data, which is the normal case right after standing up a fresh backend before traffic even moves over. A file exported before a given section existed (e.g. an older backup missing coin transfers) restores fine — that section is just skipped rather than the whole restore failing.
